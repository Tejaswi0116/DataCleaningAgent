# Data Cleaning Agent

AI-powered data cleaning agent built with Python and Streamlit for cleaning, transforming, and analyzing datasets.

## Features

- Upload CSV and Excel files
- Detect missing values
- Handle duplicate records
- Clean and transform data
- Identify data quality issues
- Generate cleaned datasets
- Download cleaned data
- Simple Streamlit interface

## Technologies Used

- Python
- Streamlit
- Pandas
- OpenPyXL
- Gemini AI

## How to Run

1. Clone or download this repository.

2. Install the required libraries:

```bash
pip install -r requirements.txt
```

3. Run the Streamlit application:

```bash
streamlit run app.py
```

4. Open the application in your browser.

## Usage

1. Upload a CSV or Excel dataset.
2. Select the required cleaning operations.
3. Run the data cleaning process.
4. Review the cleaned dataset.
5. Download the cleaned file.
